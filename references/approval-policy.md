# Approval policy

## Auto-permitted

- Read and inventory authorized sources
- Copy originals to the managed archive
- Extract metadata and calculate checksums
- Create private previews, reports, sidecars, catalog entries, and listing drafts
- Flag duplicates, rights uncertainty, and print-quality uncertainty

## Approval required

- Rename, move, overwrite, or delete a source original
- Select or replace a canonical master when ambiguity exists
- Bulk change more than ten managed records
- Retain GPS/face/sensitive metadata in a derivative for sharing
- Connect a third-party account
- Upload assets, create listings, set pricing, configure fulfillment, publish, share publicly, or send communications

## Approval payload

Every approval request must state: action, platform/destination, exact asset and work IDs, file paths, count, metadata exposure, listing fields, price/fulfillment fields when applicable, reversibility, and rollback plan.
